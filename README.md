# 方仔打工人生存指南

一个适合手机玩的静态 H5 文字选择小游戏。和方仔一起过完一天班：早高峰、早会、临时需求、午饭、下午茶、甩锅、加班邀请，一直到下班前五分钟。每一次选择都会改变精力、心情和工资，下班后生成一张可保存、可分享的鉴定卡片。

纯静态 HTML/CSS/JS，无后端、无第三方库。插图来自「方仔上班中」表情原画，已去掉白底并压缩。

## 本地预览

在本目录启动任意静态服务器，例如：

```bash
cd /workspace/games/fangzai-daka
python3 -m http.server 8770
```

然后用手机或浏览器打开 `http://127.0.0.1:8770/`。

## 说明

- 每天固定 8 个时段，每个时段会在两个情景里随机出现一个，选项 2 到 3 个
- 三条数值范围是 0 到 100；选项会带来加减，进度条带有浮动反馈
- 若任一数值在中途降到 0，会提前进入特殊结局
- 正常下班会根据数值和选择倾向生成称号，例如：摸鱼大师、卷王、准点下班侠、带薪发呆冠军、元气打工人、钱包守护者、好累但还在笑、社畜平衡术、职场老油条
- 「保存图片」会下载卡片；在 iOS 或微信里如果无法直接下载，会弹出图片并提示长按保存
- 「复制分享文案」会写入剪贴板；如果环境不允许，会弹出文本框让你手动复制
- 页脚：作者 hukx · [请作者喝奶茶](https://afdian.com/a/hukxai)

## 本地检查

```bash
node --check js/app.js
node tools/simulate.mjs
python3 -m http.server 8770
# 另开终端：
node tools/screenshot.mjs
```

`tools/simulate.mjs` 会跑大量随机对局，以及精力 / 心情 / 工资三条「尽量把该数值降到 0」的贪心策略，用来检查提前结局是否能触发、出现得是否太稀或太密。

`tools/screenshot.mjs` 会用注入脚本打开开始页、事件页和结算页（不依赖页面上的调试 URL 参数），截图写到 `/tmp/fangzai-daka-shots/`。
